# Contexto do projeto para agentes de IA

Este projeto usa Claude Code / Codex. A base de conhecimento persistente
("segundo cérebro") fica em squad-revisao-aulas/data/:

- frameworks.md — métodos e processos validados
- prompts.md — prompts testados para tarefas recorrentes
- decisions.md — decisões de arquitetura/negócio já tomadas
- glossario.md — termos específicos do domínio

Antes de propor soluções, consulte esses arquivos. Se uma decisão já foi
registrada em decisions.md, não a questione sem motivo novo — construa
em cima dela.
